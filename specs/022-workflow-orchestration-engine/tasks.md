## Notes

- [P] tasks = different files, no dependencies
- [Story] label maps task to specific user story for traceability
- Each user story should be independently completable and testable
- Verify tests fail before implementing
- Commit after each task or logical group
- Stop at any checkpoint to validate story independently
- Multiple user stories (US4, US5, US7 especially) extend the same `WorkflowExecutionOrchestrator.cs` file — when working in parallel, coordinate on that file to avoid merge conflicts even though the *tasks* themselves are logically independent
- Avoid: vague tasks, same-file conflicts without coordination, cross-story dependencies that break independent testability
