# Implementation Plan: Ribbon Menu Redesign

**Branch**: `041-ribbon-menu-redesign` | **Date**: 2026-08-26 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/041-ribbon-menu-redesign/spec.md`

## Summary

Replace the current two-row box-style expansion (trigger header + options row below) with a directional single-row ribbon pill. All `ExpandableActionGroup` (row layout) controls in the workspace shell expand as a horizontal or vertical ribbon in a direction determined by their screen placement. Trigger color changes from dark-gray to green when expanded. Active option highlight changes from amber to purple `#9C62DE`. Account menu (list layout) is unchanged.

Three files change: `CircularAction.tsx`, `ExpandableActionGroup.tsx`, `WorkspaceOverlay.tsx`. No backend changes, no new dependencies.

## Implementation Phases

### Phase A — CircularAction: direction prop + color changes

**File**: `CircularAction.tsx`

1. Add `ExpandDirection = 'left' | 'right' | 'up' | 'down'` type export.
2. Add `expandDirection?: ExpandDirection` to `CircularActionProps` (default `'down'`).
3. Derive `flexDirection` from `expandDirection`:
   - `'left'` → `'row-reverse'`
   - `'right'` → `'row'`
   - `'up'` → `'column-reverse'`
   - `'down'` → `'column'`
4. Derive `collapseOrientation` from `expandDirection`:
   - `'left' | 'right'` → `'horizontal'`
   - `'up' | 'down'` → `'vertical'`
5. Update `alignItems` on outer Box:
   - Horizontal directions: `'center'` (vertically centers trigger and pill)
   - Vertical directions: `'flex-start'` (existing — trigger left-aligned in column)
6. Update `borderRadius` on outer Box:
   - Expanded + horizontal: `radius.pill` (keeps the pill shape)
   - Expanded + vertical: `radius.lg` (existing box shape)
   - Collapsed: `radius.pill` (existing circle)
7. Update `CIRCULAR_ACTION_CHROME.collapsedBg` from `oklch(0.25 0.02 280 / 0.85)` → `#45454D`.
8. Fab `bgcolor`:
   - Collapsed: `#45454D` (explicit, not inherited from outer Box)
   - Expanded: `#2E7F26`
   - Hover: darken slightly; keep existing scale(1.05)
9. Outer Box `bgcolor`: when collapsed → `transparent` (Fab carries the color); when expanded → `CIRCULAR_ACTION_CHROME.expandedBg` (dark glass pill).
10. Content `Box` padding: for horizontal directions swap px/py to be appropriate for side-by-side layout:
    - `'left'`: `py: 1.25, pl: 1.5, pr: 0.5`
    - `'right'`: `py: 1.25, pl: 0.5, pr: 1.5`
    - `'down'`: existing `px: 1.5, pb: 1.25, pt: 0.5`
    - `'up'`: `px: 1.5, pt: 1.25, pb: 0.5`
11. Content `Box` size guard:
    - Vertical Collapse: keep existing `width: expanded ? 'auto' : 0`
    - Horizontal Collapse: `height: expanded ? 'auto' : 0` (prevents content natural height from inflating the pill taller than the trigger)
12. Pass `orientation={collapseOrientation}` to `<Collapse>`.

### Phase B — ExpandableActionGroup: purple highlight

**File**: `ExpandableActionGroup.tsx`

1. Change `bgcolor: action.highlighted ? 'warning.main'` → `bgcolor: action.highlighted ? '#9C62DE'`
2. Change `color: action.highlighted ? '#1C1B18'` → `color: action.highlighted ? '#fff'`
3. Change `'&:hover': { bgcolor: action.highlighted ? 'warning.dark'` → `bgcolor: action.highlighted ? '#7B43C0'`

### Phase C — WorkspaceOverlay: derive and pass expandDirection

**File**: `WorkspaceOverlay.tsx`

1. Import `ExpandDirection` from `CircularAction.tsx`.
2. Add a `PLACEMENT_DIRECTION` map:
   ```ts
   const PLACEMENT_DIRECTION: Record<ControlPlacement, ExpandDirection> = {
     'top-cluster': 'down',
     'right-stack': 'left',
     'bottom-end': 'up',
   }
   ```
3. Pass `expandDirection={PLACEMENT_DIRECTION[control.placement]}` to each `CircularAction` in `renderControl`.

### Phase D — Smoke test

Run the existing Vitest suite. Verify no regressions in:
- `CircularAction` tests (expand/collapse, Escape key, click-away)
- `ExpandableActionGroup` tests (row layout, list layout, highlighted state)
- `WorkspaceOverlay` tests (one-at-a-time expansion)

Manual check in browser per `quickstart.md`.

## Risk Notes

- **Horizontal Collapse height leak**: Without `height: 0` on the inner Box when collapsed, a horizontal Collapse may leave the pill taller than the trigger circle. Mitigated by Phase A step 11.
- **Badge alignment**: The `Badge` wraps the Fab inside a `flex-start` badge. In row layouts (horizontal ribbons) the badge position may shift. Check in browser — the `alignSelf: 'flex-start'` on the Badge may need to become `'center'` for horizontal directions.
- **Transition on borderRadius**: The outer Box has a transition on `border-radius`. In horizontal mode, the pill shape stays `radius.pill` always (it doesn't shrink to a circle then grow to a pill — the circle is just a tiny pill). Verify this looks clean; if not, disable the border-radius transition for horizontal directions.
